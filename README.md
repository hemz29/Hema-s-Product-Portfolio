# Hemlata Vadali — Product Portfolio

A magazine-style portfolio: a front page about how I work, and one feature article per project.

- `index.html` — front page (generated)
- `projects/` — one feature article per project (generated)
- `build/site.py` — edit story content here, then run `python3 build/site.py` to regenerate the pages
- `assets/` — shared CSS and images
- `demos/rag-simulator.html` — interactive RAG explainer (linked from the Colleague Assist PRD)
- `source-material/` — raw write-ups used for drafting (not linked from the site)
- `archive/` — earlier portfolio drafts
